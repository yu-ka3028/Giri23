# Giri23

成人向けの身体活動記録MVP。3メッツ以上の活動を週23メッツ・時の目安に積み上げます。個人差を踏まえ、できる範囲から身体を動かすための一般的な健康づくりツールです。

## 開発

```bash
npm install
npm run dev
npm test
npm run typecheck
npm run build
```

現在はサンプル活動マスタとブラウザのlocalStorageで動くデモです。記録は現在から過去24時間以内、週境界はAsia/Tokyoの月曜0時（MVPのローカル表示では端末のJST環境を想定）です。3.0 METs未満は保存・表示しますが、週目標への加算は0です。生年月日、身長、体重、性別、kcalを必須データとして扱いません（体重を任意入力した場合だけ参考kcalを表示可能なドメイン関数を持ちます）。

## データ由来・ライセンス方針

活動マスタの由来は、医薬基盤・健康・栄養研究所「身体活動のメッツ(METs)表」改訂第2版（2024年、成人版等）および原典のCompendium of Physical Activitiesです。MET値を改変・異なる値を統合せず、コード重複を前提にサロゲートIDを付け、出典バージョンを保存します。商用利用条件、MET値改変禁止、出典明記の条件を確認してデータ投入します。

参考資料の`parse_mets_table.py`はコピーしていません。PDFからCSVへ投入する処理は、ライセンス確認・監査（重複コード、章番号不一致、欠損）を含む独立したデータ取り込み工程として整備します。今回のMVPでは公開データの無断再配布を避けるため、少数のデモ候補のみを同梱しています。

健康・医療上の効果を保証するサービスではありません。週23の根拠は厚生労働省「健康づくりのための身体活動・運動ガイド2023」です。

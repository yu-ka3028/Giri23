# Giri23

成人向けの身体活動記録MVP。3メッツ以上の活動を週23メッツ・時の目安に積み上げます。個人差を踏まえ、できる範囲から身体を動かすための一般的な健康づくりツールです。

## 開発

```bash
npm install
npm run dev
npm test
npm run typecheck
npm run build
```

現在はサンプル活動マスタとブラウザのlocalStorageで動くデモです。使える時間・増やしたいMETs・時・やりたい活動を同時に指定すると、約250ms後に条件をすべて満たす候補を手軽さ順で表示します。やりたい活動は、3.0 METs以上のクイック候補から選ぶ単一選択です（先頭の「指定なし」を含む）。クイック候補は常に3.0 METs以上（週目標に加算される活動）に限定し、3.0 METs未満の活動は「あとから記録」から選択できます。候補を選んで開始し、終了時に活動と合計時間を確認・編集して保存します。進行中セッションは別キーに保持され、再読み込み後も経過時間を復元します。記録は現在から過去24時間以内、週境界はAsia/Tokyoの月曜0時（MVPのローカル表示では端末のJST環境を想定）です。3.0 METs未満は保存・表示しますが、週目標への加算は0です。週23 METs・時の計算と候補算出に個人の体重は使用せず、kcal計算もMVPの対象外です。

## データ由来・ライセンス方針

活動マスタの共通出典は、中江悟司ほか『身体活動のメッツ(METs)表』改訂第2版（2024年、成人版）および原典のCompendium of Physical Activitiesです。候補カードでは活動ごとに説明と、コード・METs・公式原文・アプリによる参考訳・出典リンクを確認できます。活動候補は2024 Adult Compendium of Physical Activitiesの指定行と照合済みです。原文引用は改変せず、引用が裏付けるのは活動内容とMETs値です。表示する時間と回数はアプリ作成の開始目安であり、METs・時は回数でなく実施時間で計算します。回数は公式根拠ではなく、公式日本語訳や個人への推奨でもありません。MET値を改変・異なる値を統合せず、コード重複を前提にサロゲートIDを付け、出典バージョンを保存します。サイドステップは低衝撃エアロビクスの具体化で、引用行に直接記載された種目ではありません。商用利用条件、MET値改変禁止、出典明記の条件を確認してデータ投入します。

参考資料の`parse_mets_table.py`はコピーしていません。PDFからCSVへ投入する処理は、ライセンス確認・監査（重複コード、章番号不一致、欠損）を含む独立したデータ取り込み工程として整備します。今回のMVPでは公開データの無断再配布を避けるため、少数のデモ候補のみを同梱しています。家事の候補は「床・カーペットを掃く」および「掃除機をかける」として表示します。運動候補には、公式行に明記されたジャンピングジャックと、低衝撃エアロビクスを具体化したサイドステップを含みます。

歩行メニューは、3.0 METs/code17170を「止まらず一定のペース」、3.8 METs/code17190を「駅などへ少し急いで向かう」、4.8 METs/code17200を「腕を振って意識的にテンポよく歩く」という日常的な表現で案内します。また、3.8 METs/code17081の野原・丘の散策を収録します。日常例はアプリ作成の目安で、個人差があるため走り出す時点などを断定しません。健康・医療上の効果を保証するサービスではありません。週23の根拠は厚生労働省「健康づくりのための身体活動・運動ガイド2023」です。
